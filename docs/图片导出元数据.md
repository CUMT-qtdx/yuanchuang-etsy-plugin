# 导出时自动处理图片元数据

本功能集成于现有下载与导出入口，没有独立工具页面。预览、选图、精修和内部图片存储继续使用原图。点击下载时生成内存副本；单张失败明确报错，批量和 ZIP 跳过失败图片并继续导出其余图片。

## 导出路径

| 入口 | 调用路径 |
|---|---|
| 创作区、角度图、预览弹层、普通生图、会话图片 | `ImageDownloadLink` → `downloadImages` → `cleanImageMetadata` → Blob 下载 |
| 画廊批量下载 | 选择项全部图片 → `downloadImages` → 收集逐张结果，下载成功项并提示失败项 |
| 画布图片和图片文件节点 | `downloadImages` / `downloadCanvasFile` → 同一处理模块 |
| 海报 PNG 导出 | 原有海报渲染 → `downloadImageBlob` → 同一处理模块；清理本身不重绘 |
| 商品／创作 ZIP | `downloadImageZip` → `/etsy/export` → `exportProduct` → 对所有参考图、结果、材质样本与方向图处理后打包 |

ZIP 包含逐张的 `图片元数据处理报告.json`，记录成功数量、失败数量、每张图片状态与失败原因。图片读取失败、文件丢失或元数据处理失败均只跳过该图片；全部失败时返回错误，不生成空 ZIP。现有商品 JSON、视觉规则和文案继续按原先资料包内容导出；这项功能处理图片内部元数据。

## 保留规则与状态

- 支持 JPG、PNG、WebP，包括渐进式 JPEG、透明图、APNG 和动画 WebP。
- 对 EXIF、XMP、IPTC、PNG 文本及日期字段清理非必要隐私数据。保留作者、版权、许可、方向和色彩解释所需字段；ICC 与像素压缩数据原样复制。
- 默认不提供删除作者、版权和 C2PA 的功能。
- C2PA 可验证的 `c2pa.hash.data` 排除范围允许等长改写，并验证原文件与输出文件的数据摘要；不更改凭证和受绑定字节。
- C2PA 规则无法安全解析、受保护范围涵盖隐私字段、盒哈希／外部凭证等情况，自动保留原文件并显示“未清理”；仅清理安全部分时显示“部分清理”。不声称验证了签名者身份。
- MPF／多图 HDR 的偏移索引必须保持完整，因此保留原文件并标注“未清理”。
- 损坏文件、未知图片格式及无法安全保留署名的扩展元数据会明确报错，这些图片不会进入下载或 ZIP；其余图片继续导出。
- 状态包括“已清理”“部分清理”“未清理”“无需清理”，在下载后以非模态提示显示；部分清理与未清理提示保留至关闭或下次导出。
- 元数据处理不移除 SynthID 或可见水印，也不改变像素内容。

## 开发验收

`npm run test:metadata` 验证格式、隐私字段、版权作者、C2PA 跳过与等长处理、损坏文件拒绝。

`npm run test:metadata:browser` 使用本机 Chrome，验证真实下载、批量、现有创作界面及 ZIP。需以 `PLAYWRIGHT_PACKAGE_ROOT` 指向本机已有 Playwright 的 node_modules 目录；模型使用隔离测试夹具。`scripts/create-metadata-fixtures.py` 可重新生成像素样本。

本功能随 2.1.3-etsy 提供，更新说明见 `docs/releases/v2.1.3-etsy.md`。
