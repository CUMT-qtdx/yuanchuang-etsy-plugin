## 2. 小挂件 vs 桌面人物摆件的 5 大核心差异

1. **展示与受力方式**：摆件立在桌面（底部接触台面与投影）；小挂件主要为**顶部挂绳承重垂挂**（树枝/横绳/挂钩）或**90° 俯拍平铺**（木板/亚麻/纯白底面，挂绳自然舒展），不能强行压在画幅底部 92% 站立，也不能把挂绳当作“悬浮配件”删掉。
2. **挂绳与顶帽硬件**：`jute twine loop`（粗股扭纹麻绳）、`thin cream cotton string`（细棉绳）、`braided cord loop`（编织短环）、`felted ornament cap`（圆柱/皇冠毛毡顶帽）、`tiny metal eyelet / jump ring`（微型金属羊眼钉/挂环）必须保留原材质与真实连接，严禁被毛毡化成粗毛线或悬空断开。
3. **手工表层刺绣保护**：小挂件大量使用羊毛/棉线表层刺绣（雪花、星芒、叶脉、花卉、螺旋线圈、法式结粒绣、袜跟平针锁边缝线）与微型彩色毛毡珠；负面词禁止“针织毛衣/编织网格底材”的同时，必须显式豁免并保护“针毡底面上的手工装饰刺绣与缝线”。
4. **微缩比例羊毛手感**：掌心尺寸挂件在近景下纤维尺度相对更大，应呈现**饱满微鼓的手工轮廓、清晰可见的短羊毛交错纤维与克制的自然边缘微绒（soft stray-fiber halo）、高饱和温润羊毛发色**，避免磨皮塑料感或过度松散蓬乱。
5. **规划与改款维度**：面对挂件或 4～9 件成套挂饰时，规划维度应优先围绕「挂件轮廓形状、刺绣与针毡嵌色纹样体系、顶帽/挂绳工艺、成套配色协调与展示布局」，不对无脸挂件强行分配服饰、肢体或表情。

## 3. 融入策略（自动识别 + 可选展示预设）

- **自动识别**：在 `design-strategy.ts` / `material-policy-v2.ts` / `composer-v2.ts` 中通过规划字段 `productForm: 'ornament' | 'figurine'`（并对旧稿及用户描述做轻量关键词识别）自动判定是否为挂件/挂饰；
  - 判定为 `figurine`（桌面摆件/人物/动物玩偶）时，**100% 沿用既有桌面摆件提示词逻辑，零回归**；
  - 判定为 `ornament`（挂件/圣诞球/袜子/吊饰/钥匙扣挂件）时，自动注入挂件质感补充、挂绳/顶帽/金属环保护、手工刺绣豁免与构图保护。
- **新增 2 个摄影展示预设**（[photography-v1.ts](../../src/etsy/felt/photography-v1.ts) / [photography-contract.ts](../../src/etsy/felt/photography-contract.ts)）：
  - `hanging-display`（**悬挂展示**）：树枝/横拉麻绳自然承重垂挂 + 柔和节日暖光散景 + 留足顶部挂绳空间不裁顶；
  - `flat-lay`（**俯拍平铺**）：90° 正上方俯拍 + 木板/亚麻/干净浅底 + 挂绳自然舒展 + 克制松针/松果/干橙片角落点缀。
