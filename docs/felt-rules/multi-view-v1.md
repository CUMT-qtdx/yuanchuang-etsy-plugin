# 定稿多角度一致性 v1.0

初始适用插件版本：`1.15.4-etsy.33`。后续`.34`材质修复见[material-lock-v1.md](material-lock-v1.md)，取消本页所述“AI通过自动追加参考”，改为只有用户确认的角度参与结构辅助。

## 使用方式

初次探索仍选择3至8图与创意幅度。摄影背景现为单一选择入口，原“保留原图背景”勾选移除；选择“其他 / 自定义”显示最多1000字的环境描述。旧数据中勾选与预设冲突时，显示之前实际生效的“保留原背景”，不重写历史图片。

先选中满意图片，必要时精修构图与背景，再点击“确定为主设计”。这时保存该图摄影、构图、清晰度档位、材质部件及身份锚点。多角度面板会显示锁定的画幅和主体占比目标。后续上方探索控件的变动不影响这组视角。如果要换整组背景、材质或造型，先精修主图，再确认为新的主设计。

固定细节直接进入多角度Prompt的最高优先级补充；编辑后点击“更新固定细节”。设定卡可继续人工编辑并保留历史，旧卡的角度不作为新卡参考。角度图仍可单独修正、重做、下载和预览，原图与父子版本保留。

## 三种创作任务究竟控制什么

实际任务文字在 `src/etsy/creation-flow.ts` 的 `taskInstruction`；改动幅度在 `src/etsy/design-strategy.ts` 的 `planningRules` 和 `generationRules`，材质实际执行在 `src/etsy/felt/composer.ts`。

| 任务 | 发给模型的核心要求 | 适用参考 |
|---|---|---|
| 参考图改款 | 在参考商品上按创意档位改变款式；用户锁定特征优先 | 已有商品或已完成设计 |
| 转成毛毡作品 | 必须把原陶瓷、树脂等材质转为毛毡；保留用户指定的形态和混材配件；幅度仍单独控制 | 其他材质的立体商品 |
| 二维转立体毛毡 | 必须增加合理体积、厚度、前后结构与连接，再转为毛毡；平面形态不作为必须保留项 | 插画、卡通、平面图案 |

所有初次探索都默认启用毛毡材质，因此忘选不一定完全不能用，但可能把“忠实转换”做成“创意改款”，或没有充分立体化。想保留参考形象，选择对应转换任务搭配“小幅调整”，并明确写保留项。新多角度模式不使用这三个任务或创意档位。

## 独立规则与真实派发

新增文件 `src/etsy/multi-view/consistency-v1.ts`，标记 `[multi_view_consistency_v1_0]`。未改写 `library-v1.ts`、`photography-v1.ts`、`composition-v1.ts`；原三个v1.0规则继续用于探索和主图精修。

多角度进入独立Prompt分支，只匹配定稿主图已实现的材质与摄影表现，不重新应用通用压实/毛绒程度、默认背景、60%默认构图或创意延展。记录中的 `modules` 为实际调用的多角度模块；主图继承来源另存为 `multiView.anchor.inheritedModules`，避免把“继承主图”误记成“重套材质规则”。所有模型继续走现有生成接口，运行时仍保存实际最终Prompt。

第一张参考永远是定稿主图，是唯一身份/画质锚点。局部角度修正时第二张是待修图并明确标记。后续参考最多补至5张，按角色区分人工确认、AI检查通过和用户上传隐藏结构参考，不让它们变成另一个设计模板。

按所选角度依次执行左侧→右侧→背面→斜侧面→正面。每张生成并保存后，等待本次一致性检查结束，再派发下一张；一组同时只运行一张生图。AI检查五项全部有依据且PASS，或人工确认一致的当前设定卡版本，才参与后续参考。每个角度仅保留最新合格参考版本。未通过、检查失败或漏项的图照常保存和显示，但不传播；下一张继续依据主图与其他合格参考。生成失败可单独重试，没有无限自动返工。

逐张生成会比并行等待更久，但提高后续视角获得有效结构参考的机会。每个角度通常1次生图＋1次检查；定稿设定卡复用，无新增循环规划调用。预算、取消、显式重试、重启恢复继续复用原工作流。已完成项目不会因打开而重发或重写业务档案。

## 锁定与检查

- 身份：同一三维轮廓、比例、姿势、五官、帽子/领口结构、颜色位置、配件位置及纹样。
- 材质：匹配主图实际毡化密度、纤维可见度、哑光、柔软度、边缘厚度和微小细节，避免侧背面粗化或变成通用简化玩偶。
- 摄影：匹配主图背景/台面/墙、光向与氛围、相机距离、主体在画面中的大小及留白。主图为1:1则保持1:1；主图已明确其他画幅则跟随，避免强制裁成方图。
- 占比：保留主图保存的近似目标，同时以主图实际呈现为准；侧面轮廓宽度自然变化，不拉伸身体强迫相同外接矩形。
- 隐藏面：最保守地延续已知结构，不增加无依据装饰；不可见部分仍列为未知，允许补充角度参考或固定细节。

检查结果分别保存 `identity`、`composition`、`material`、`accessories`、`photography` 五项状态和证据。缺项或缺证据视为UNKNOWN，不把一个笼统PASS当作完整通过。AI结果仍是建议，既非三维重建约束，也非像素测量或实物证明。

## 启用与回归核对

生成新角度后，在“商品资料与高级选项 → 视觉规则与实际提示词”中查看该图Prompt，应该出现 `[multi_view_consistency_v1_0]`，且无 `[REFERENCE_DESIGN_V2]` 或通用材质重设段。导出中的 `visual-rules.json` 保存锚点、参考角色、角度和实际规则；商品档案中保存五项检查结果。历史角度不伪标为新模式。

`scripts/multi-view-consistency.test.mjs` 覆盖自定义背景、Prompt分离、顺序与检查等待、参考递增、不合格图隔离、摄影锁定、局部修正、失败重试、恢复及实际检查模型合同。`scripts/felt-photography-browser-test.mjs` 覆盖单一背景入口、自定义输入与恢复、定稿后改变探索设置仍保持主图摄影，以及下载、提示词查看和窄屏。

工程测试使用本地Mock，不消耗真实模型额度。真实视觉一致性依然受当前模型能力和可见参考限制，本次不会声称像素级一致或保证所有隐藏面真实。
