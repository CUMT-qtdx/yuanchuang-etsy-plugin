# 三种创作任务的实际提示词段

这些是生产代码 taskInstruction 返回的原文；最终探索Prompt还会拼入改动幅度、每张方案、用户要求、羊毛毡及摄影构图规则。

## 参考图改款

任务是在参考商品上改款，按创意档位控制变化。

## 转成毛毡作品

任务是把其他材质的商品转成毛毡作品。保留用户指定的角色与造型关系，将商品表现改成毛毡；原图的陶瓷、树脂等材质不属于保留项。材质转换是本次必做任务，不受小幅调整的幅度限制。采用当前羊毛毡视觉规则，用户锁定的造型和配件优先。

## 二维转立体毛毡

任务是把二维插画或平面图案转成立体毛毡造型。保留指定的角色特征，设计合理的体积、厚度、前后结构、姿态与连接关系；平面图的平坦形态不属于保留项。立体化与毛毡转换是本次必做任务，不受小幅调整的幅度限制。采用当前羊毛毡视觉规则，用户锁定的造型和配件优先。
