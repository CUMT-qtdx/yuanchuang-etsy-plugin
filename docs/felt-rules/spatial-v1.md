# 主图位置与近远侧 v1.0

`spatial-v1.ts` 在主设计中保存 `spatial.sourceFacing` 与 `anchors`。每个锚点只记录主图画面左/右/中/不确定、物件名、连接位置和可见证据。仅在主图正面或背面明确时换算身体左右；斜侧或不确定不强行推断。

正面主图画面左侧对应角色自身右侧。界面右侧槽脸朝画面左，角色自身左侧在近侧，因此原本在自身右腰的篮子应在远侧。程序计算期望遮挡，再交给生图与检查模型，避免分别由模型口述“左右”造成自相矛盾。

新设定卡分析和材质取样仍在同一次请求里完成，不增加每个角度的常规调用。旧主设计的 `prepare-spatial` 借用既有主图分析阶段与预算控制，仅显式操作时启动；中断结果不明不自动重发。补查只更新空间记录及未经人工编辑的 AI 左右文字，保留历史设定卡、材质参考与旧图片。手动编辑过的锁定文字仍保留，并优先于自动规则。

检查中的 `spatialChecks` 必须与锚点名称对应，独立观察待检图中的配件近远侧；缺项不能视为通过。待检图、主图和另一侧比较图逐张以文本标签绑定。放大的主图局部不混入这次整体检查，避免比例与方向误读；局部仍用于后备材质修复。

这是对生成约束与检查合同的修复，不提供三维几何重建保证。AI 可能漏看附着点、误读遮挡或材质；不可据检查结果宣称实物一致。
