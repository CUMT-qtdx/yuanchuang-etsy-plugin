# 定稿主图材质锁定与单张修复

初始适用版本：`1.15.4-etsy.34`。后续`.35`的首次侧背面直接生成见[first-pass-material-v1.md](first-pass-material-v1.md)；本页局部取样流程继续用于检查和后备修复。本次只处理材质漂移，左右视角与几何判定未宣称解决。

## 本次针对的问题

实际使用中出现“主图细短、紧实、柔软，角度图却被重新解释为粗长卷丝、网状孔隙和过锐的帽片边缘”。同一次AI检查还可能在issues里写材质变化，却在分项中给PASS。旧流程会将AI通过的图片加入后续参考，从而有传播表面变化的机会。

本次没有重写已采用的 `needle_felt_v1_0`、`felt_photography_v1_0` 或 `felt_composition_v1_0`，没有改变图片尺寸、账号或默认质量档，也没有新增自动返工循环。

## 实际处理

新增 `src/etsy/multi-view/material-lock-v1.ts`，标记 `approved_material_lock_v1_0`。

1. 定稿分析同时观察主图已呈现的材质，保存1至2个部件描述及对应局部区域，不用“更真实”之类泛词代替纤维形态。旧设定卡缺少这部分时，首次操作最多补一次材质分析，复用原分析模型和调用账本。
2. 浏览器从归档主图原文件按区域直接裁剪PNG，尺寸保持原始像素，不AI重画、不放大、不锐化。局部图片与主图ID、区域及描述一起保存。模型区域可能判断不准，可在折叠的“主图材质参考”查看样本，不把区域定位当作客观测量。
3. 每张角度的参考顺序为：主图、主图材质局部、需要修正的角度（若有）、剩余人工确认/上传结构参考，总数仍最多5张。材质只来自主图及其局部，其他角度仅帮助理解结构。
4. AI检查通过的角度不再自动参与后续生成。只有用户点击“核对一致”的角度可以作为结构参考；主图始终作为材质和身份基准。
5. 每张已有角度下新增“只修材质”，使用原图作为父版本，要求保持当前角度、主体形状、姿势、配件、背景和构图，只恢复对应主图材质。原图和其他角度都保留。
6. 在原有一次图片检查内额外比较五项：纤维粗细与长度、压实度与孔隙、短绒/卷圈、边缘厚度/毛晕、哑光/微观对比。每项要求主图与待检图对比依据，缺项为UNKNOWN；任一项DRIFT或问题列表包含材质问题时，材质不得再显示PASS。

材质提示词强调“匹配主图对应部件”，而不是把全部部件压成同一种材质。主图本来存在的局部卷毛应保留；不能把细短纤维增强成丝瓜络、卷线网或夸张毛丝，也不能磨皮抹掉真实纤维。

## 如何使用与追溯

在多角度面板点击“生成”或任意已有角度的“只修材质”。首次会显示准备主图材质状态；成功后可展开“主图材质参考”查看裁剪的真实局部。样本随项目保留，下一次不会重复分析。

“只修材质”通常增加1次生图和1次检查；缺少旧主图材质记录时首次另有最多1次分析。仅浏览图片/样本不调用模型。分析失败、超时或取消不自动再次调用，也不冒充准备成功。受原调用预算和每阶段尝试次数限制。

实际Prompt在高级选项可查；角度图的规则记录包含 `approved_material_lock_v1_0` 及 `materialReference`，导出包括全部样本图、来源区域、父子版本和 `materialComparison` 检查结果。旧图不会伪写新规则，也不会加载时自动重做。

## 验证范围

`scripts/material-lock.test.mjs` 验证材质区域合同、旧项目一次补分析、并发去重、原像素保存/派发、错误阻断、版本保留和矛盾检查收敛。Chrome回归实际点击“只修材质”，并用逐像素比较确认浏览器裁剪PNG与主图对应区域完全一致。

这些工程验证不能证明所有真实模型结果都已达到主图观感。材质匹配仍由图像模型完成；本方案增加可见局部依据并阻断自动传播，但最终需并排查看真实修复图，不把AI的PASS等同于用户验收。
