# 多角度方向约束 v1.0

## 适用范围

仅在定稿后的左右侧面生成中启用 `product_view_direction_v1_0`。首次侧背面仍使用完整主图作为材质与身份基准；不修改 `needle_felt_v1_0`、`felt_photography_v1_0`、`felt_composition_v1_0`。

## 方向约定

界面左右以主图画面为准，而不是角色解剖左右：

| 界面槽位 | 输出脸部朝向 | 近侧身体 |
| --- | --- | --- |
| 左侧 | 画面右边 → | 角色自身右侧 |
| 右侧 | 画面左边 ← | 角色自身左侧 |

例如主图中角色右手持花、左手扶帽：左侧图朝右时，持花的右手位于近侧；右侧图朝左时，扶帽的左手位于近侧。配件在画面中的位置可以随着整体转身改变，不能据此认定换手。旧候选代码曾把脸朝右与角色自身左侧近侧同时要求，几何上矛盾，现已统一。

`direction-guide.ts` 生成不含商品像素的方向示意图，作为第二张参考；第一张始终为主图。示意图只表示方向，提示词禁止复制其形状、颜色、鼻子、箭头与文字，不调用额外生图模型。背面不附加左右示意图。“只修材质”保留已有角度，不强制改变方向；“纠正朝向”和“重做”从主图生成新版本。

## 检查与不确定性

检查请求先展示待检图，再展示主图与辅助参考。另一侧最新图单独标为 `opposite-view-check`，仅用于检查两张是否同向、重复或镜像，不作为首次生图的外观依据。

模型须返回实际观察到的脸部方向、是否完整侧面、持物侧是否一致、成对关系及证据。错向、斜侧冒充正侧、换手、同向或镜像会标为需修正；字段不全或证据不足为不确定。两侧文件字节完全相同时，工作流确定性地标为需修正，即使模型报告通过。此检测不保证发现所有经重编码或轻微变化的重复图。

AI 检查为建议，隐藏面推断和视觉模型误判仍需人工核对。任何左右图都保留“纠正朝向”入口，旧图没有方向报告时显示“朝向尚未检查”；不自动重发旧任务、不无限重试。

## 模型选择

未单独保存时跟随当前图片模型，不因存在 Grok 通道而自动预选。显式选择通过 `set-view-model` 立即保存到主设计，刷新仍保留；服务端生成请求也读取已保存选择。保存失败回滚本次字段及存档版本。已保存的其他模型选择不会在加载时被静默改写。
