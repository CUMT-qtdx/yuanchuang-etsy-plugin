## 材料目标与分类

主体从未纺羊毛经针刺压实形成连续的三维体积，短小、不规则纤维嵌入毡体；正常距离紧实哑光，近看仍有纤维，既不能变成布壳填充玩偶，也不能磨成塑料。面部另有紧实纤维与五官可读性约束。

| 分类 | 仅在存在相应部件时使用 |
|---|---|
| sculpted_needle_felt | 三维针刺羊毛主体、头脸、耳、四肢及明确的立体针毡配饰 |
| loose_wool_or_curly_fleece | 明确存在的松毛、头发、卷须或局部绵羊毛 |
| flat_felt_sheet | 明确裁剪、薄片或平面毡片部件 |
| woven_or_knitted_clothing | 真实棉麻布裙、针织围巾等服装 |
| mixed_material_accessory | 珠眼、金属、织物丝带、刺绣和装饰针脚 |

`feltProfile.materialComponents` 每项记录 `part`、`category`、可选 `region`、`evidence`、`observedMaterial`。观察材质与目标分开：可以记录原图为针织布偶，但候选目标的脸和四肢仍是针毡。旧实验版的七类记录可兼容映射到新分类，不迁移或重写历史项目。只有普通 `clothing` 时保留材质未知，不自动当作毡衣或布衣。

## 组装方式

候选版不是附加在旧材质规则后面，而是替换本次材质模块。每个实际存在的材料类别只输出一组规则；面部规则只在识别到面部时输出。旧版 MR/PART/MIX 材质正文不再同时注入候选版。

组装流程：读取原设计与部件分类 → 清除本模块拥有的完整旧版本块 → 确认目标分类 → 纠正明确的设计材质冲突 → 只组装选中版本 → 保存最终提示词与纠正记录。

`material-assembly.ts` 只替换可明确定位的材料短语，不删除含姿势、配件或背景的整句。例如生成文本的 `knitted white rabbit doll` 改为 `needle-felted white rabbit doll`；已明确棉布裙的 `felt dress` 改为对应织物描述。合法针织围巾和装饰针脚保留，否定要求如 `No knitted face` 不被误改。

无法安全解析的主体材料冲突、同一部件的矛盾分类、不完整版本块，在图像请求前报错；明确用户要求不会被静默改写。英文为主要生成语言，当前规则覆盖已验证的中英文材料表达；不声称规则式解析能识别任意自然语言矛盾。纠正记录见 `materialCorrections`。
