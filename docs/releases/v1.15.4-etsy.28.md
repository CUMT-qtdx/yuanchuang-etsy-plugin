# 三档创意规划重新区分

参考图规划不再复用“尽量复现原图”的反推角色。三个按钮分别执行以下设计任务：

| 档位 | 任务 |
|---|---|
| 小幅调整 | 同款变化；保留姿态、轮廓和主要比例，探索配色和小细节 |
| 适度改款 | 同系列新款；改变服饰、表情、适度动作或主题造型 |
| 大胆创作 | 参考图作为灵感；四个方案各要求至少两个主体设计维度变化，其中一个涉及轮廓、姿态、比例或主体组合 |

用户明确写下的保留/修改要求优先。规划会在同一次调用内自检四方案差异；不给员工新增填写门槛，也不新增自动模型调用。

新版规划带策略版本，初次生图和失败重试使用相同档位指令。选定结果后的“修改这张图”只修改当前结果，不重新执行最初的大幅重设计。视觉检查会读到当前方案的计划变化，避免仅因姿态不同于原图而提示修回原款。

界面说明和待生成的四个方向随档位切换；高级选项中显示实际下发生图指令。旧图片和旧项目提示词不自动重写。

验证：93 项业务回归、11 项基础单测、类型检查、DOM E2E、Google Chrome 同图三档流程及原参考图流程通过；测试模型为本地 Mock。测试确认了指令传递和工作流行为，没有用真实付费模型生成三档图片，最终设计幅度仍需在实际生成中比较。
