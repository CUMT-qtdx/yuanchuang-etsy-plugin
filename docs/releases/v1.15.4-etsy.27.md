# 生图与商品文案五项修复

这次更新解决逐图文案错存、失败后难以继续、商品事实校验、局部文案失败及机械排版问题。

- 保存、改图、导出显式绑定图片。自动保存串行执行，编辑冲突保留草稿并提供载入最新版和恢复草稿入口。
- 生图失败、写盘失败及中断恢复正确结束依赖阶段。停止后仍可选择成功图；失败图片可显式重试，保留修改要求及累计调用记录。
- 材料、尺寸和单位按确认资料核对，常见商品承诺按各自依据校验。生成稿局部清除错误内容并提示待补字段；人工修改有冲突时保留输入。
- 单个标题、译名或标签异常不再隐藏全部合格文案。补齐仅替换待补字段，保留合格内容及员工编辑；补齐失败仍可查看已有部分稿。
- 正文保持完整句子，不再强行凑表情或按固定词数截断。复制与导出使用同一公开文本格式，导出前等待保存。

回归包括隔离工作流故障、两窗口 Chrome 编辑、冲突恢复、导出内容对照和原有主流程。测试模型为本地 Mock，未消耗真实模型额度。

已有项目和原稿保留；更新不会自动重新调用模型。事实校验覆盖已测试的常见材料、尺寸、单位与承诺表达，不代表能判断任意语言的所有商品主张。
