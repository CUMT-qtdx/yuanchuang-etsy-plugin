# 创作图片大图预览与单张下载

此前参考图工作台的生成结果只显示为静态缩略图，没有绑定大图查看入口。本版补齐：

- 点击图片或“查看大图”，在页面中央打开原图预览。
- 图片完成并归档后即可查看，不需要等质检、标题或文案结束。
- 支持放大、缩小、适应窗口、双击放大/恢复、左右按钮及键盘方向键切图。
- 右上角关闭、Esc、点击遮罩都可退出；关闭后键盘焦点回到原入口。
- 弹窗“下载这张原图”和每张卡片“下载原图”分别保存单张图片，不需要导出整个 ZIP。
- 使用原图接口，下载不重采样、不重新编码；文件名包含项目、方案与版本。
- 预览与下载不改变文案当前选图，不触发模型调用；原有整组图片与文案导出仍保留。

Google Chrome 验证覆盖：文案生成中预览、横图/竖图/方图、连续切图、缩放、三种视口、键盘、读取失败和刷新恢复。单图下载已与存储原文件逐字节比较。
