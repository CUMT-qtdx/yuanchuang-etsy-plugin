## 更新内容

1. 新增导出时自动处理图片元数据。点击原有下载／导出按钮即可使用，覆盖单张下载、批量下载、图片预览、画布图片和商品 ZIP；平台内原图继续保留。
2. 支持 JPG、PNG、WebP，直接处理文件元数据，保留原始格式、尺寸、像素内容、色彩配置和方向。
3. 默认保留作者、版权和 C2PA 来源凭证。仅清理能够安全处理的字段；受凭证保护或无法确认安全范围时保留原文件，并明确显示“部分清理”或“未清理”。
4. 批量下载和 ZIP 遇到个别失败图片时，自动跳过该图片，其余正常导出，并列出未导出文件及原因；全部图片失败时不生成文件。ZIP 附带逐张处理报告。

本功能处理文件元数据，不移除 SynthID 或可见水印。
