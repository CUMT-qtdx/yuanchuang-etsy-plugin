# 元创 Etsy Studio 2 · 2.0.0-etsy.6

相对 `2.0.0-etsy.5`，这一版只改界面。生图规则、材质流程和已有功能都没有删。

- 标题改为「元创 Etsy Studio」，版本号单独放在标题下面。
- 工作台改成中间看图、右边操作。参考图、创作任务、改动幅度、摄影、生成、方案、修改、多角度、文案和商品资料都还在。
- 摄影与构图固定展开，不再带折叠箭头。
- 右边栏加宽到 340px。栏内自己滚动，生成按钮固定在栏底，不用把整页翻到最底下才看得到。
- 主按钮、选中状态和版本号改回上一版绿色。

安装包：`releases/dickpy-dsh-imagegen-2.0.0-etsy.6.tgz`。

本版没有新增付费生图，也没有做羊毛毡画质验收。
