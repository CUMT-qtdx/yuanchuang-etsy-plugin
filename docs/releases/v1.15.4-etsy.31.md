# 多角度图片入口与进度提示

此前确定主设计后首先展示文字设定卡，尚未请求角度图片时没有图片区域，容易让人误以为功能只生成文字。本版将图片生成作为主要操作。

- 标题改为“多角度图片”，显示当前基准图缩略图。
- 明确显示绿色“生成 N 张多角度图片”按钮，数量跟随勾选和已有结果变化。
- 未生成的角度先显示占位卡，并注明点击生成后图片会出现在此处。
- 提交中、排队、生成中、失败和已保存状态均就地展示；失败可单张重试。
- 设定卡移至图片区域之后，显示为“形象设定（辅助信息）”，默认折叠；提交生图后自动收起已展开设定。
- 操作错误在当前面板显示，不必滚回页面顶部查找；提交期间禁用重复操作。
- 已有角度不因再次点击按钮而重复生成，原有单图预览、下载、调整和重做继续保留。

本版不自动替用户触发生图。需点击图片生成按钮后才会调用图片模型，打开设定卡或进入页面不会计费。

验证：隔离Chrome复现“设定卡完成、角度请求0次”状态，覆盖空状态、选择数量、被拒请求、提交反馈、单图失败/重试、图片出现、设定卡折叠、刷新和窄窗口；均使用Mock模型。
