# 首次侧背面直接保留主图材质

多角度面板新增“侧面 / 背面模型”，与主图和正面/斜侧面的图片模型分开。已有Grok渠道时预选它，用户可改回，选择随该主设计保存；全局模型与账号不改。

正常生成侧背面直接参考完整主图，使用简短照片编辑规则保留表面，不再叠加放大的材质局部及长篇材质描述。每个角度只生图一次，不自动再修一遍。旧角度“重做”也可走此路径，所有原版本保留。“只修材质”继续作为后备。

此修改依据同一主图的真实出图验证：本样本Grok侧背面的身体表面较细密，GPT多种提示词/参数变化未呈现稳定优势。仍存在帽檐等结构细节偏差和左右问题，不能宣称与主图完全一致或对所有商品有效。

保留原材质/摄影/构图规则、项目、文案、导出和单图下载。补齐Grok订阅比例值的实际参数转发。详见 `docs/felt-rules/first-pass-material-v1.md`。
