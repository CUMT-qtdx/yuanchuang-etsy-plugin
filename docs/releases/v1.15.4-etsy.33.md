# 自定义背景与独立定稿多角度

修复“保留原背景”在下拉框与复选框重复且显示矛盾的问题：统一在摄影背景选择，新增“其他 / 自定义”及可保存的环境描述。旧项目按原实际效果兼容，不改已有图片。

定稿多角度使用独立 `multi_view_consistency_v1_0` 模式，唯一身份锚点为选定主图；锁定其材质密度、纤维、细节、摄影、画幅、相机距离与主体占比，不读取探索创意档位和后来改动的摄影设置。原三份v1.0材质/摄影/构图规则正文不变。

按所选角度逐张生图并检查，左侧、右侧、背面优先；合格的已生成角度可作为后续辅助结构参考，主图始终第一。检查五项可见一致性并显示依据，缺项、失败或不合格图不自动传播，无自动返工循环。

固定细节以高优先级进入实际Prompt，设定卡及父子版本继续保存，角度可单独调整、重做、预览、下载。原探索3至8图、模型入口、文案和项目导出继续保留。三种创作任务补充明确提示，它们只影响探索、不影响定稿多角度。

工程回归使用隔离Chrome与本地Mock。更多实现及使用说明见docs/felt-rules/multi-view-v1.md。
