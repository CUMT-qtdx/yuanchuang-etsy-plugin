# 2.0.0-etsy.9

增加独立的「Gemini 原生（generateContent）」渠道协议，用于 TokenFree Creative 等原生 Gemini 图片服务。

- 在 Etsy 工作台顶部将「创作任务」和「分辨率」并排显示，提供 1K / 2K / 4K，默认 2K，并保存选择。
- 首次生成、继续修改、重试和定稿多角度使用明确选择的分辨率；切换旧项目时恢复对应图片档位。
- 仅支持 1K 的型号禁用高档位；不能透传分辨率的 Gemini Chat 渠道明确提示改用原生渠道。
- 补齐 Nano Banana 2.1 的型号识别，去除错误的「未知协议」标签。

- 按所选模型拼接 `/v1beta/models/模型名:generateContent`。
- 支持文生图、参考图、画幅、1K/2K/4K 参数及候选图片数量。
- 同时处理 `fileData.fileUri` 下载链接和 `inlineData` Base64；下载第三方图片不携带 API Key。
- 原生生成最长等待 5 分钟；已存在的 Images 和 Chat 协议保持原有请求路径与格式。
- 配置步骤见 `docs/TokenFree香蕉生图_配置教程.md`。

协议配置正确不等于供应商当前可用。真实请求返回 502 时显示原始错误，不自动重复提交计费任务。
