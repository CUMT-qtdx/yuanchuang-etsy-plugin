# 主图材质参考与只修材质

针对多角度细密毡面变粗、出现卷丝/网状纹理的问题，增加独立主图材质锁定模块。定稿分析提取部件表面描述与局部位置，直接从主图原像素裁剪最多两处PNG，并随每张角度派发；不重画、放大或锐化样本。

旧项目首次按需补一次材质分析，之后复用。AI通过的角度不再自动传给后续图，用户确认的角度只辅助结构。每张角度新增“只修材质”，保存新版本，保留原角度、主图和其他结果。

材质检查新增五项可见证据；存在材质问题或证据缺失时，不再同时显示通过。继续复用原模型、任务队列、调用预算及导出，原材质/摄影/构图v1.0规则不改写。

本次范围仅为材质，未宣称解决左右视角和所有几何一致性。工程回归与实际视觉验收分开记录。详见 `docs/felt-rules/material-lock-v1.md`。
