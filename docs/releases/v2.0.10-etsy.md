# 元创 Etsy Studio 2.0.10-etsy

本版修复审查中的前三项问题：

1. 读取参考图过程中切换到新创作或历史项目时，取消旧读图并隔离异步回调。旧图不会写入刚切换的项目。
2. 生图执行超时从队列真正开始运行时计时，排队等待不占预算。外层预算覆盖原生生成和结果下载；真正执行超时仍会停止等待并保留结果不明状态，不自动重复生成。
3. 已生成图片的归档和再次编辑统一为单图 20 MiB 的本地上限。保留原图字节和像素，不通过缩图规避限制。手工上传参考图片仍为每张 10 MiB、合计 20 MiB。

版本编号改为 `2.0.10-etsy`。后续依次为 `2.1.1` 至 `2.1.10`、`2.2.1` 至 `2.2.10`，每组十版。继续使用一个 EXE 安装或更新。

定制版的在线替包保护独立于版本名；下载入口指向元创项目 Releases。应用内自动更新留待后续开发。
