# 2.1.1：插件内更新

工作台右上角增加更新入口。打开插件会检查元创 GitHub Releases；有新版本时显示提醒，点击后查看版本和说明。

1. 点击「下载更新」，查看下载进度。
2. 下载器核对发布附件的大小和 SHA-256。
3. 点击「重启并更新」，保存当前编辑内容并确认。
4. 独立更新程序退出 DSH、安装同一个单文件 EXE，然后重新打开 DSH。

生图、分析或文案任务未完成时不会启动安装。安装失败时尝试恢复本机保存的旧包，并记录失败状态。

发布方式沿用一个 EXE。旧版第一次需要通过安装包获得本功能，以后使用插件内按钮。

版本依次为 `2.0.10-etsy → 2.1.1 → … → 2.1.10 → 2.2.1`，每组十版。
