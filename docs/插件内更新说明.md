# 插件内更新使用与发布

## 员工操作

打开插件时，右上角显示「检查更新」；发现新版后显示「发现新版 版本号」。

点击后选择「下载更新」。下载完成并校验通过后，点击「重启并更新」，保存当前正在编辑的内容并确认。更新结束后 DSH 自动重新打开。已有商品、图片、模型渠道和 API Key 沿用本机设置。

有生图、规划或文案任务时，先完成这些任务再更新。下载可在使用插件时进行，安装需要退出 DSH。

首次从旧版切换时仍需双击安装一次带该功能的版本。

## 维护者发布

每个正式 GitHub Release 保持一个附件：`Update-Yuanchuang-Etsy-版本号.exe`。插件只识别元创仓库，不访问原作者发布或 npm 安装定制版。

发布附件需要 GitHub 提供 `sha256:` digest。缺少附件、多个附件、文件大小不一致或 SHA-256 不一致时停止自动安装。

打开插件检查一次，之后每15分钟检查；「检查最新版」绕过本机缓存。网络不可用时正常生图不受影响。

本机更新记录与安装回执位于自己的 DSH 数据目录 `plugin-updates/yuanchuang`。已保留旧包时，失败后尝试离线恢复；日志只包含更新结果，不读取模型密钥。

## 验收范围

已使用隔离的模拟新版发布、真实 HTTP 下载、真实 EXE 安装、独立 DSH 程序与虚拟配置完成成功及失败回退测试。公共 GitHub 版本查询也已验证。

2.1.1-etsy 为首个带应用内更新的正式版本。旧版先安装本版一次；以后发布更高版本时，从插件内下载、校验并更新。完整公开跨版本更新将在发布下一个正式版后继续验证。
